# Essay candidates

Tick the ones you want (about 50 to 60). Written from memory with no browsing, so every link is checked afterwards by `node scripts/essays/check-links.mjs`, which marks dead ones with `⚠ DEAD`. A `⚠ CHECK` mark means the site refused the check (not necessarily dead). Each line: title, author, publication, year, link, note (up to 12 words).

Every link goes to the original publisher, the author's own site, or a public-domain archive (Wikisource, Project Gutenberg, and similar). Years are the year of first publication or delivery.
